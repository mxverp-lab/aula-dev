Guías rápidas de programación

Mxverp reúne herramientas gratuitas para practicar conceptos habituales de programación. Las utilidades funcionan en tu navegador; evita pegar datos personales, claves reales o información confidencial en cualquier herramienta online.

Cómo convertir números entre bases

El sistema decimal utiliza diez símbolos (0–9), el binario utiliza dos (0 y 1), el octal utiliza ocho y el hexadecimal utiliza dieciséis (0–9 y A–F). Para convertir un número, introdúcelo en el campo correspondiente. Por ejemplo, el decimal 255 equivale a 11111111 en binario, 377 en octal y FF en hexadecimal. En informática, el binario ayuda a representar datos y el hexadecimal permite leer valores binarios de forma más compacta.

Qué es una expresión regular (regex)

Una expresión regular describe un patrón de texto. Puede servir para localizar palabras, comprobar formatos sencillos o extraer fragmentos de una cadena. En el probador de arriba, escribe el patrón, configura sus flags y añade un texto de ejemplo. La coincidencia con un patrón no garantiza por sí sola que un dato sea correcto en todos los contextos; por ejemplo, validar direcciones de correo de forma completa requiere más que una regex sencilla.

Cómo validar y formatear JSON

JSON es un formato de intercambio de datos que utiliza objetos, listas, cadenas, números, valores booleanos y null. Las claves y las cadenas deben ir entre comillas dobles. Usa el formateador para mostrar la estructura con sangría y el minimizador para eliminar espacios innecesarios. Si aparece un error, revisa las comas, las comillas y los corchetes o llaves que abren y cierran cada estructura.

Comandos Git básicos

Git permite registrar y revisar cambios en un proyecto. git status muestra el estado de los archivos; git add prepara cambios; git commit crea un registro local; y git push envía commits a un repositorio remoto configurado. Antes de usar comandos que reescriben o descartan cambios, comprueba el estado del repositorio y asegúrate de que no vas a perder trabajo.

Buenas prácticas para crear contraseñas

Una contraseña larga y única para cada servicio reduce el riesgo de que una filtración afecte a otras cuentas. Este generador crea una cadena aleatoria en el navegador. No reutilices la contraseña generada en varios sitios y considera utilizar un gestor de contraseñas de confianza. No compartas contraseñas ni las incluyas en ejemplos públicos.
